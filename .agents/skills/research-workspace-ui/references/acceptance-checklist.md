约定：每轮 UI 改动至少完整走一遍 §1–§3；触及阅读器或断点的改动加跑 §4。

- [ ] `npm run check` 全绿（基线：88 文件 / 1628 测试，35.9s；出现新失败先定位再继续）

## 3. 场景走查

布局与导航：
- [ ] 左右两栏同时打开：PDF 列仍占多数宽度，无水平滚动条
- [ ] 拖拽两侧栏到最小/最大值，再超出拖拽，确认 clamp 生效、无布局破碎
- [ ] 键盘调宽：焦点在分隔条上 ←/→ ±16px、Home/End 到边界
- [ ] 长论文标题：正确截断（…），页码输入与缩放控件不被挤压、可点击
- [ ] 多标签/多篇论文切换：布局与阅读位置恢复正确
- [ ] 窄窗口（≤759）：侧栏变抽屉，scrim 点击、Escape（无 dialog 时）可关闭；背景不滚动串扰
- [ ] 恢复默认布局（如有）：宽度/开合/预设回到默认值，论文数据不受影响

阅读器：
- [ ] 缩放（+/−/百分比/适应宽度）：适应宽度与手动缩放互斥切换正确
- [ ] 页码输入跳页、上一页/下一页、阅读位置在刷新后恢复
- [ ] PDF 选段 → 引用高亮/标注锚点位置正确（缩放与窗口缩放后复测一次）
- [ ] 纸张模式四种（跟随外观/原始/暖纸/深灰）切换，彩色块颜色不漂移（immersive 脚本覆盖）
- [ ] 右侧面板：三 chip 切换；AI 输入框固定底部、答案区独立滚动；面板内滚动不穿透到 PDF
- [ ] 面板浮层态（≤1100px）：不遮挡主操作按钮，关闭后 PDF 交互正常

设置窗口：
- [ ] 每页在内容少时无大片底部留白（窗口自适应），内容长时内部滚动
- [ ] 主题/深色程度/密度/字号档切换即时生效且刷新后保持
- [ ] AI 服务页：供应商、密钥（只写不回显）、预算控制功能不回归
- [ ] 头像在个人页可配置（若本轮迁移过）

## 4. 静态界面规则（按 file:line 报告问题）

无障碍与交互：
- [ ] 纯图标按钮有 `aria-label`；操作用 `<button>`，导航用 `<a>`；无 `<div onClick>`
- [ ] 可见焦点（`:focus-visible`），无裸 `outline: none`；浮层/吸顶不遮挡焦点元素
- [ ] `prefers-reduced-motion` 下无位移动画；动画只涉及 transform/opacity，无 `transition: all`
- [ ] dialog/抽屉内 `overscroll-behavior` 防背景滚动串扰
- [ ] axe-core（page-checks.runAxe）无新增 violation

视觉与文案：
- [ ] 颜色全部来自 Token，无硬编码色值（grep `#[0-9a-fA-F]\{3,6\}` 核对新增行）
- [ ] 新间距来自间距刻度，控件高度一致；同一视图只有一个主按钮
- [ ] 长文本容器有 truncate/clamp/break-words；数字用 `tabular-nums`
- [ ] 中文文案：主动语态、具体动词（"保存更改"而非"提交"）、错误说明修法、空状态给出下一步
- [ ] 省略号用 `…`；快捷键标注用不间断空格

## 5. 红线（出现即打回，不论其余多好看）

- PDF 坐标系：文字层、选段定位、引用高亮、标注锚点、虚拟滚动任一失效
- 主题首帧闪烁（theme-init.js 与 theme.ts 不同步）
- 文本被裁切、滚动区域丢失、浮层遮住主操作、背景滚动串扰
- 759/1100 断点 JS 与 CSS 行为不一致
- 修改了 AI 请求协议、供应商逻辑、密钥存储；动了论文/标注/知识数据
- 引入新 npm 依赖或 UI 框架（未经授权）
- 浅色、纯黑、中间深色任一态出现蓝灰底或对比度不达标（contrast.mjs 报告为准）
