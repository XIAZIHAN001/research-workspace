## 6. 已知限制（如实）

- BibTeX 解析器不支持跨行 @string 变量替换与 xdata 等扩展——坏条目跳过并说明，
  不会产生错记录。
- 复习调度按整天粒度（SM-2 经典形态），"忘了"当次会话内重见。
- 报告导出为 Markdown 单文件；知识图快照未内嵌（引用均带页码可回跳）。
