### 它是什么
科研 Agent 技能集（面向 Claude Code / Codex / OpenCode / pi），16 个 skill：
survey / brainstorm-ideas / know-me-better / autoresearch / write-paper /
review-paper / write-slides / create-advisor / dump-chat-history + 7 个 how-to-*。

### 读到的关键机制（不是功能名，是可迁移的做法）
- **how-to-build-kb**：绝不凭记忆生成 BibTeX，必须对权威源核验；DOI/arXiv
  双标识去重；`.raw/` 缓存验证过的元数据 JSON，bib 只从 JSON 生成；
  cite key 规则 `lastname_year_firstkeyword`；扩展 KB 时只追加、保留用户编辑。
- **survey**：7 种检索策略（landscape / adjacent subfield / cross-vocabulary /
  cross-method / historical lineage / negative results / benchmarks）；
  多策略并行 + 按 title/DOI 去重合并并记录来源策略；NOTES.md 三节
  （领域全景 / 开放问题 / 瓶颈）；报告结构 Overview → Key Questions →
  Technical Approaches → Open Problems（4-8 条带紧急度的排序表）。
- **review-paper**：九准则 → 处理位置映射；严重度 high/med/low；
  **claim ↔ citation 支持性检查**；"Flag uncertain — do not assert"、
  "never silently correct"、"never fabricate a citation"；断链检查。
- **how-to-review-figure**：18 条 rubric（11 通用 + 7 科学图），带严重度。
- **autoresearch**：显式阶段状态机 + 门禁（gate），**Verify, don't trust**
  ——从磁盘产物反推阶段，缺产物就回退；封存验证器 + 私有 holdout；
  attempt 预算 + keep/drop + 反思报告。
- **brainstorm-ideas**：六条对话原则（澄清动机 / 鼓励深想 / 标记不确定并区分
  观点与证据 / 引入邻域事实 / "You think, I fetch" / 激发理论兴趣）；
  append-only 会话日志，**日志先行后回复**。

### 对本项目的判断
本项目是**论文消费**工作台（读→拆→联），sci-brain 是**研究生产**工具链。
不应把生产流程整体搬进来；值得搬的是它的**证据纪律**与**结构**。

对照现有代码确认的缺口（事实）：
- `Paper` 只有 `doi` / `arxivId` 字符串，**无 citeKey、无 BibTeX、无验证状态**
- `knowledge` 域已有 `ConceptEvidence`（逐字引文）与"待验证：无逐字引文"徽章，
  但**没有聚合视图**告诉用户整篇论文哪些结论站得住
- AI 面板的"相关论文"是单一推荐，**没有策略维度**
- 无项目级领域笔记、无图表审查清单

### 建议（按优先级，未写代码）
1. **P1 引文核验 + .bib 导出** —— 唯一"不做就会产生错误"的功能。当前元数据来自
   PDF Info 字典（不可信自由文本），没有任何一条被权威源验证过。
   做法：`Paper.citation`（citeKey / bibtex / verifiedAt / verifiedBy / mismatches[]），
   DOI→Crossref 核验，导出项目级 .bib。
2. **P1 论断证据覆盖率** —— 纯视图，复用已有 `evidence` 数据；项目级"未验证论断"清单。
3. **P2 检索策略分组** —— 把 7 策略做进"找相关论文"，每条标策略来源，可换策略再跑一轮。
4. **P2 项目级领域笔记** —— NOTES 三节，可从概念图谱生成初稿。
5. **P3 图表审查清单** —— 18 条 rubric 评分，结果落成结构化批注（**需改 annotation 接口，须先获批**）。

**明确不建议**：write-slides（Typst 工具链）、autoresearch 的 attempt 循环
（依赖 git worktree + 代码实验）、write-paper（写作工具，超出定位）、
dump-chat-history（本项目无多会话历史）。
